# parseaple

A collection of TypeScript libraries for parsing Apple's binary formats.

## Packages

| Package | Description |
|---|---|
| [typedstream](./packages/typedstream) | Parser for Apple's typedstream/NSArchiver binary format |

## Development

This is a [Bun](https://bun.sh) monorepo.

```
bun install
```

### Build all packages

```
bun run build
```

### Test all packages

```
bun run test
```
